

# 💰 FinanceFlow - Personal Expense Tracker

![FinanceFlow Banner](https://via.placeholder.com/800x400/6366f1/ffffff?text=FinanceFlow+Dashboard)

**Live Demo:** 🌐 [https://rpy2006.github.io/FinanciaFlow/](https://rpy2006.github.io/FinanciaFlow/)

A modern, responsive web application for tracking personal finances, managing budgets, and visualizing spending patterns. Built with vanilla HTML, CSS, and JavaScript - no frameworks required!

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Live Demo](https://img.shields.io/badge/Demo-Live%20Site-brightgreen.svg)](https://rpy2006.github.io/FinanciaFlow/)
[![Pure JavaScript](https://img.shields.io/badge/Built%20with-Pure%20JavaScript-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## ✨ Features

### 📊 Dashboard & Analytics
- **Real-time Financial Overview** - Track income, expenses, savings, and balance at a glance
- **Interactive Charts** - Visualize expense breakdown and income vs expenses comparison using Chart.js
- **Monthly Statistics** - Beautiful stat cards displaying key financial metrics
- **Recent Transactions** - Quick access to latest financial activities with categorization
- **Category-wise Spending** - Understand where your money goes with detailed breakdowns

### 💸 Transaction Management
- **Dual Entry System** - Add both income and expense transactions seamlessly
- **Smart Categorization** - Pre-defined categories for better organization (Housing, Food, Transportation, etc.)
- **Recurring Transactions** - Set up recurring income entries automatically
- **Multiple Payment Methods** - Track cash, card, bank transfers, and digital payments
- **Date Tracking** - Organize transactions by specific dates

### 🎯 Budget Planning
- **Category-based Budgets** - Set spending limits for different categories
- **Flexible Periods** - Weekly, monthly, quarterly, or yearly budget cycles
- **Budget Monitoring** - Track expenses against set budgets in real-time

### 🎨 User Experience
- **Dark/Light Theme** - Toggle between themes for comfortable viewing in any lighting
- **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- **Mobile-friendly Navigation** - Collapsible sidebar optimized for smaller screens
- **Smooth Animations** - Enhanced user interactions with CSS animations and transitions

### 💾 Data Management
- **Local Storage** - All data persists securely in your browser's local storage
- **Export Options** - Download comprehensive reports as PNG images or PDF documents
- **Data Backup** - Save and load financial data locally for backup purposes
- **Clear Data** - Option to reset all data when needed

## 🚀 Quick Start

### Live Demo
Visit the live application: [https://rpy2006.github.io/FinanciaFlow/](https://rpy2006.github.io/FinanciaFlow/)

### Local Development
```bash
# Clone the repository
git clone https://github.com/rpy2006/FinanciaFlow.git

# Navigate to the project directory
cd FinanciaFlow

# Open index.html in your browser
# Or use a local server for better performance:
python -m http.server 8000
# Then visit http://localhost:8000
```

### Prerequisites
- Modern web browser with JavaScript enabled
- No additional dependencies or installations required!

## 🛠️ Technology Stack

- **Frontend**: Pure HTML5, CSS3, JavaScript (ES6+)
- **Charts**: [Chart.js](https://www.chartjs.org/) for beautiful data visualization
- **Icons**: [Font Awesome 6.4.0](https://fontawesome.com/) for modern icons
- **Fonts**: [Google Fonts - Inter](https://fonts.google.com/specimen/Inter) for typography
- **Export**: [html2canvas](https://html2canvas.hertzen.com/) & [jsPDF](https://parall.ax/products/jspdf) for report generation
- **Storage**: Browser Local Storage API
